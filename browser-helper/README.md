# StreamNest 浏览器助手

此扩展用于抖音和快手的公开、非 DRM、已获授权视频。它只在用户从 StreamNest 主动创建任务后，在后台打开对应平台页并捕获服务器明确返回为 `video/mp4` 的媒体请求。捕获后由本机 StreamNest 服务直接下载并显示进度，管理器不会跳转到平台页面。

另有一个可选的 B 站会员会话功能：仅当你在本机网页主动点击“同步 Edge B 站会话”时，扩展才读取当前 Edge 配置里 `bilibili.com` 域名的 Cookie 并交给 `127.0.0.1:8788`。会话只保留在解析服务内存里，最多 8 小时；网页和任务记录不会收到 Cookie。这个功能不保证会员视频一定能下载，也不处理 DRM 或账号无权观看的内容。

## Edge 安装

1. 打开 `edge://extensions/`。
2. 开启“开发人员模式”。
3. 点击“加载解压缩的扩展”。
4. 选择本目录 `browser-helper`。
5. 刷新 `http://localhost:3000/`，页面应显示“浏览器助手已连接”。

更新扩展文件后，需要在扩展管理页点击本扩展下方的“重新加载”，版本应显示为 `0.3.6`。弹窗应先显示“助手版本 0.3.6，已就绪”；若始终显示“助手脚本未启动”，说明新版脚本尚未加载。点击“同步本机 B 站会话”后会显示读取或连接阶段，超时也会恢复按钮并给出中文错误。成功后回到网页等待会话状态更新，并对原任务点“重新解析”。B 站与本机服务权限需要在 Edge 中确认。

Chrome 的安装方式相同，扩展管理地址为 `chrome://extensions/`。

抖音/快手功能不会导出 Cookie、密码或登录凭据，只把媒体地址以及必要的 Referer、User-Agent 等非敏感请求头交给本机服务。B 站 Cookie 仅按上述用户主动点击的流程用于本机会员解析，不会发送到外部服务器、网页界面或日志；不要把浏览器扩展安装到不信任的配置中。
