StreamNest Windows 便携版

1. 把整个 ZIP 解压到本机文件夹（不要直接在压缩包里运行）。
2. 双击「启动StreamNest便携版.cmd」。首次启动通常需要几秒钟。
3. 浏览器将打开 http://localhost:3000/ 。如果没有自动打开，请手动输入这个地址。
4. 下载的视频和图片只保存在本文件夹下的「下载内容」。

本程序只在本机 127.0.0.1 上运行，不需要租服务器或公网 IP。
运行期间请勿移动或删除 runtime、node_modules、dist 等文件夹。
如果 3000 或 8788 端口已被其他程序占用，请先关闭占用程序后重试。
启动失败时，可查看 work\launcher-logs 里的日志。

部分平台受地域、站点变更或登录状态影响，不能保证每条链接都可下载。
只下载你有权保存的公开、非 DRM 内容；程序不会绕过付费、验证码或 DRM。
B 站已登录会员画质如需使用浏览器助手，请自行在 Edge 里加载随包 browser-helper，
并仅在自己的电脑上主动同步自己的 B 站会话。发布包不含任何用户账号或 Cookie。
